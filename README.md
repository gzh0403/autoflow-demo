# AutoFlow 演示样品（P2 可点击原型）

**这是一份公开演示样品，不是商业产品。** 门店、顾客、工单与车牌（例如 沪A·AF001、沪A·AF008）都是虚构演示数据，不代表真实经营，也不接真实支付或云环境。

预期公开地址：https://gzh0403.github.io/autoflow-demo/

工作品牌名：**AutoFlow**（确认前使用）。演示门店名：**AutoFlow 演示门店**。

界面与数据始终标注：**演示样品 · 虚拟数据 · 非真实经营数据**。

视觉为**建议视觉，待创始人确认，未锁定**。方向是精密汽车工场 / 精洗工作室：冷色石墨、深灰、离白混凝土色，以淡铁蓝作为主操作色。没有套用木序的昭和复古风格。

## 如何打开

不需要安装、不需要 npm、不需要本地服务器。

1. 用浏览器直接打开本目录下的 `index.html`（可双击，或把文件拖进 Chrome / Edge / Safari）。
2. 顶部工具条可切换角色（顾客阿明 / 店员小陈 / 老板林）、切换「宽屏布局 / 手机容器」、打开体验指引，以及一键重置演示数据。
3. 操作结果保存在浏览器 localStorage。刷新后（未点重置前）会保留。点「重置演示数据」会恢复预置虚拟数据。

若个别浏览器对本地文件的限制导致页面空白，可用任意静态服务器在本目录启动后再打开，但这不是必须步骤。

单测（可选）：在本目录执行 `node tests/rules.test.js`。

## 页面导航

三端共用同一套数据。一端操作后，切换角色即可在其他端看到状态变化。

### 顾客端（底部：首页、预约、会员、我的）

- 门店首页、门店介绍
- 服务项目与详情、技师列表与详情
- 我的车辆（一客多车；可新增、编辑；预约必须绑车）
- 填写预约（项目、车辆、技师、日期与时段；跨日项目显示多日占用；工位按类型匹配且不回退；同车同段不可重叠）
- 我的预约与详情（进度、照片、质保；符合规则时可取消）
- 会员与次卡（余次、流水、领取演示次卡）
- 质保记录可点进详情（含质保信息与该工单 / 车辆的完工照片）、消费记录、我的

### 店员端（底部：今日、顾客、我的排班、我的）

- 今日看板：可换日期，可按时间或按工位查看（跨日单会标出第几天）
- 预约 / 工单详情：确认、取消、到店、开始、登记照片、完工、核销、登记质保、逾期未到
- 查询顾客与车辆，可为顾客建档
- 我的工作安排（前台视角的排班与已接单，只读）

### 老板端（底部：看板、预约、经营、设置）

- 经营看板（店员无权限）
- 预约与工位管理（与店员相同的处理能力）
- 经营：消费记录与统计、会员与次卡（发放演示卡、查流水）、质保记录、顾客与车辆档案
- 设置：门店资料与规则、服务项目、员工与排班、工位管理、权限说明（演示环境不做真实开通，禁止空表自提）

## 核心流程体验路径

打开页面后，也可点工具条里的「体验指引」。建议先走下列路径（全部为虚拟数据）：

1. **车辆档案**：以顾客阿明进入「我的 → 我的车辆」，可见 沪A·AF001、沪A·AF008 两台车。可新增一辆再去预约。
2. **施工预约与进度**：顾客为其中一辆车预约「精洗护理」，提交后为「待确认」（此时已占位）。切换到店员小陈，在「今日」看板换到后天，打开该单并确认。状态会同步回顾客端。
3. **跨日工位占用与冲突**：预置「顾客小周 · 全车隐形车衣」已占用今天和明天的 **3 号贴膜工位** 与 **技师小河**。跨日占用是连续多个营业日的工位与技师区间锁，不是把单日工位简单改个名字。顾客端预约「全车改色膜」，技师选小河、日期选明天，应被拒绝并写明冲突的技师 / 工位；请改期或更换技师，不会把贴膜单改分到精洗工位。同一车辆同一时段也不可重叠。店员或老板取消该跨日单后，占位释放，同一类型工位可再约。
4. **到店施工、照片与核销**：店员打开阿珍今日「已到店」精洗单：开始施工 → 登记演示占位图 → 「完工并核销」（短单合并步骤，状态仍写入完工与核销）。结算只记录方式，不是真实支付。
5. **会员次卡**：阿明有精洗次卡（预置余 7 次）。将其精洗单核销并选择该卡，余次减 1 并写流水。再核销应被拒绝。小周洗车次卡余次为 0，核销时应提示不足。禁止无凭证直接改次数（店员「我的」里有越权演示按钮）。
6. **简易质保**：顾客端打开「质保记录」，点进阿明 沪A·AF001 的太阳膜记录，可查看质保详情与该工单的完工照片。店员 / 老板可在贴膜类工单完工时登记新的门店质保（不对接膜厂官方接口）。
7. **越权**：顾客详情页的「尝试确认 / 核销」、店员「尝试改价 / 打开经营看板 / 直接改次数」均应由规则拒绝，而不是只靠藏按钮。

规则要点：默认店员手动确认；先约后付。状态为 待确认 → 已确认 → 已到店 → 施工中 → 待交车 → 已完成。待确认至待交车占用工位与技师；已取消与逾期未到释放占用；已完成不能再次核销。工位按类型匹配且类型不符即不可用；同一车辆同一时段不可重叠。店员端已核销工单会保留「已核销、不可重复核销」说明。
